# 🌤️ WeatherTrack

**A responsive real-time weather application built with HTML, CSS and JavaScript.**

Search cities, check your current location, view forecasts, save favorite cities, and get useful weather insights.

</div>

---

## ✨ Features

* 🔍 Search weather by city
* 📍 Current location weather
* 🌡️ Celsius / Fahrenheit toggle
* 🌤️ Detailed current weather
* 🕐 12-hour forecast
* 📅 7-day forecast
* ⭐ Favorite cities
* 🕘 Recent searches
* 💡 Weather insights
* 🌅 Sunrise & sunset
* 📱 Responsive design

---

## 🛠️ Tech Stack

**Frontend**

* HTML5
* CSS3
* JavaScript (ES6+)

**APIs & Browser APIs**

* Open-Meteo API
* OpenStreetMap Nominatim API
* Browser Geolocation API
* Browser LocalStorage API

---

## 🌦️ Weather Data

WeatherTrack provides:

* Current temperature
* Feels-like temperature
* Weather condition
* Wind speed
* Humidity
* Atmospheric pressure
* Visibility
* Hourly temperature & rain probability
* 7-day high & low temperatures
* Sunrise & sunset times

---

## 💡 Weather Insights

The application analyzes current weather conditions and provides simple recommendations based on temperature, rain, wind, humidity, and thunderstorms.
