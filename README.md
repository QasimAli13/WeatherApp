# 🌦️ Weather App

A clean and responsive weather application that provides real-time weather information for any city using the OpenWeather API.

---

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature
- 💧 Humidity information
- 💨 Wind speed
- ☁️ Weather condition with icon
- 📱 Responsive design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API
